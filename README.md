## Features

- **Dark Professional Theme** with glassmorphism effects
- **Premium Animations** — Intersection Observer, fade, slide, scale, floating particles
- **Custom Cursor** with hover effects (desktop only)
- **Scroll Progress Bar** and smooth scrolling
- **Responsive Design** — fully optimized for mobile, tablet, and desktop
- **Accessibility** — WCAG 2.1 AA compliant, keyboard navigation, skip links, ARIA labels
- **SEO Optimized** — semantic HTML, structured data (JSON-LD), Open Graph, Twitter Cards
- **Performance** — lazy loading, optimized images, minified code structure
- **Live Chat Widget** with quick replies
- **Working Contact Form** via FormSubmit
- **Project Filtering** by category
- **Certificate Gallery** with modal preview and category filters
- **Testimonial Carousel** with auto-play
- **Professional Career Timeline**
- **Google Maps Integration**

## Tech Stack

- **Pure HTML5** — semantic, accessible markup
- **Pure CSS3** — CSS variables, flexbox, grid, animations, glassmorphism
- **Vanilla JavaScript** — modular, no frameworks
- **GitHub Pages** — hosting

## SEO & Structured Data

- JSON-LD Person, WebSite, WebPage, BreadcrumbList, and ProfessionalService schemas
- Open Graph and Twitter Card meta tags
- Canonical URLs
- robots.txt and sitemap.xml
- Web App Manifest
